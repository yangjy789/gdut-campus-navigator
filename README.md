# GDUT Campus · 校园探索与智能导览

面向广东工业大学大学城校区的全栈校园信息平台。访客在同一入口浏览校园、搜索地点、收藏、查询步行地图并使用 AI 助手；管理员维护同一份地点目录。

## 产品能力

- **校园探索**：51 条初始地点资料，覆盖教学区、生活东区、生活西区；关键词、旧称与类别搜索，规划建筑独立标记。
- **交互地图**：Leaflet 展示学校地图，列表与图上标记联动，详情可设置起终点。
- **个人收藏**：收藏保存在当前浏览器，可筛选收藏地点。
- **步行地图**：从目录确认起终点，生成百度地图步行查询链接。距离与实际路线由地图服务提供，本地不输出未经核验的米制距离。
- **AI 助手**：基于公开资料的知识问答及来源展示；自然语言识别校园地点，名称不唯一或未收录时要求澄清。
- **统一管理中心**：认证登录后维护地点、区域、类别、别名、说明、规划状态、图上位置和资料来源；访客目录与问答读取最新记录。
- **工程能力**：SQLAlchemy + Alembic 迁移、MySQL 持久化、CSRF 与会话保护、请求限速、Docker Compose 三服务部署。独立保留堆优化 Dijkstra 算法模块与交叉验证测试，未将其独立验证路网当作当前校园实际路网。

## 技术架构

Vue 3 / TypeScript / Element Plus / Leaflet → Nginx → FastAPI → MySQL。

AI：硅基流动 Xing4.0-29B；Chroma 本地字词向量检索与实时目录词形排序。该检索基线不是预训练中文语义向量。模型不决定地点编号、建筑入口或实际距离。

## 本机运行

已有 Docker 环境时，填写本机 `.env.deploy`，然后：

```powershell
docker compose --env-file .env.deploy up -d --build
```

访问 `http://localhost:8080/`；管理中心 `/admin`。密钥和密码不进入镜像、前端或版本库。首次管理员凭据仅在后端运行目录内保存。

本机开发：先配置 `.env`，运行 `.venv\Scripts\python.exe -m alembic upgrade head`，再启动 `scripts/start-backend.ps1` 和 `scripts/start-frontend.ps1`。当前运行的容器会占用 8000 端口，开发服务应先释放该端口或另设端口。

## 数据与边界

地点名称与地图来源：学校 2026 年建筑、景观命名公告及地图附件，完整来源记录在 `data/public_campus/campus.json`。原始资料保存在本地研究目录，数据库目录通过迁移 0004 首次导入，以后维护和删除不会被重启覆盖。

地图使用近似图上位置，未启用 GPS 定位；不把透视图像长度换算成实际米数。导航跳转是第三方地图衔接，不应描述成自建完整真实校园路网。地图版权归原权利人；公开上线前需确认底图使用许可。

项目当前在本机运行，云端公开地址与 HTTPS 尚未配置。测试与功能记录见 `docs/统一产品验收.md`；开发历史见 `docs/开发顺序.md`。
