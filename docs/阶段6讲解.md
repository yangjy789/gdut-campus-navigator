## 密钥与费用

本机 .env 中的 ZHIPU_API_KEY 已由你填写，后端只在本机读取；浏览器不会收到该密钥。
固定使用此前选择的 glm-4.7-flash，若 ZHIPU_MODEL 改成其他型号，当前实现会拒绝调用，不自动转为收费型号。
检索不调用在线向量 API，也不需要下载预训练嵌入模型。智谱免费服务的限额和可用性由平台决定，本项目不能保证其一直可用。
问题和检索到的公开校园资料/项目说明会发送至智谱，数据库密码、管理员密码和会话不会发送给模型。

## RAG 的流程

问题 → 生成本地字词向量 → Chroma 查询相近资料 → 将最多 3 条资料交给智谱 → 校验回答格式和引用编号 → 前端显示回答与来源。

这叫检索增强生成：先找资料，再让模型依据资料组织语言，降低凭空编造校园信息的机会。
资料不足时要求模型说明缺少依据；如果本地根本没有检索到相关资料，就直接返回“资料不足”，不发送模型请求。
提示约束和引用校验不能保证回答永远没有事实错误，正式发布前还需要扩大资料集和评测集。

## 本地向量的限制

当前使用确定性的字词哈希向量：英文词、中文二字/三字片段通过 SHA-256 映射到 1024 维，归一化后由 Chroma 按余弦距离检索，再过滤没有字词重合或相似度过低的结果。
它是一种免费、可复现的词形检索基线，不是经过训练的语义向量。换一种说法、同义词和复杂问题可能匹配不到，也可能匹配到仅部分相关的资料。
后续可以替换为经过验证的本地中文嵌入模型，并比较召回率；目前不能在简历中声称已实现高质量中文语义检索。

索引位于 D 盘项目的 .runtime/chroma。资料内容的指纹用于区分索引版本，资料变更后重启服务会建立新版本，不会查询旧版本中已删除的条目。
Chroma 的默认嵌入函数未启用，文档和问题都显式传入本地向量，匿名遥测设置为关闭。

## 文件分工

| 文件 | 作用 |
| --- | --- |
| backend/app/knowledge.py | 文本分词、免费向量、Chroma 索引和检索 |
| backend/app/qa.py | 问答接口、智谱调用、引用校验、限速与错误提示 |
| data/knowledge/campus.json | 人工整理的带来源知识条目 |
| frontend/src/components/AssistantPanel.vue | 提问、等待、错误、回答与来源展示 |
| scripts/check_assistant.py | 使用真实网页代理检查模型及无资料情况 |
| backend/tests/test_qa.py | 隔离测试检索、回答格式、来源和服务错误 |

模型返回 JSON，包括状态、正文、引用的资料编号。后端拒绝未提供过的资料编号，以及没有引用的“已回答”结果。
浏览器只显示来自本地知识文件的来源链接，不接受模型自行生成的外部链接，也不把模型正文当 HTML 执行。
提问为独立单轮，上一条网页回答不作为下一条问题的上下文；本版不保存聊天历史。
单个进程限制每个客户端每分钟最多 10 个提问，同时最多 1 个模型请求；生产多实例时需共享限速与监控。
2026-11-21 增加拥堵缓解：收到 1305 后等待约 2 秒、4 秒（附少量随机延迟）重试，总共最多 3 次请求，并检查 50 秒剩余时间预算。账户限速、余额不足、权限或参数错误不会进行这种自动重试。前端等待时提示不要重复发送。
这只能缓解临时拥堵，不能保证解决智谱端持续过载，也不会自动切换收费模型。新增 3 项重试行为测试，本次问答专项测试共 17 项通过，前端构建通过。
