# GDUT Campus · 校园探索与智能导览平台

## 可用于简历的项目介绍

面向广东工业大学大学城校区构建全栈校园导览平台，整合校园地图、地点检索、浏览器收藏、智能问答、步行地图衔接与管理中心。基于 Vue 3、TypeScript、FastAPI、MySQL、Chroma 和大模型 API 实现，使用 Docker Compose 完成本机容器化部署。

## 项目经历条目

- 设计前后端共用的校园地点目录，将 51 条初始公开地点资料导入 MySQL，通过 Alembic 管理迁移，实现地点、区域、别名、图上位置和资料来源的增删改查。
- 使用 Leaflet 实现校园地图与地点列表联动、区域筛选、起终点选择和本地收藏；将已确认的地点名称衔接至百度地图步行查询，避免自行输出未经核验的道路距离。
- 构建带来源校验的 RAG 问答流程，结合 Chroma 字词向量检索和实时目录排序；通过明确句式与模型工具调用识别起终点，名称有歧义时要求澄清，后台更新可即时用于目录问答。
- 实现基于会话摘要的管理员认证、CSRF 校验、请求限速及错误信息处理；本机与容器内 107 项自动测试通过，完成三服务构建、数据库迁移和功能验证。

## 面试时应能说明的边界

1. 当前地图是校园示意图，图上位置不是 GPS 坐标或精确入口；实际步行路线与距离由外部地图服务提供。
2. 内部保留堆优化 Dijkstra 算法与独立路网测试，但当前访客页面的真实地点导航不是该算法基于完整校园实测路网生成的结果。
3. 当前检索是字词哈希向量基线与实时目录词形排序，不应说成自行训练的中文语义模型。
4. 收藏保存在浏览器，没有实现跨设备账号同步；当前为本机容器化运行，公网服务与 HTTPS 未配置。
5. 51 条资料包括 1 条在来源中标为规划中的建筑，不应称为“51 座已建成建筑”。地图底图对外发布需确认使用许可。

不应写入简历的未验证指标：并发人数、线上用户数、召回率、毫秒级响应或已实现全校精确导航。
