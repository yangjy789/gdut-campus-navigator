## 保存发生了什么

Vue 表单 → Axios 携带登录 Cookie 和操作校验码 → FastAPI 检查会话与输入 → SQLAlchemy 更新 MySQL → 返回保存结果。
校验放在后端，不能只依赖前端隐藏按钮。直接绕过网页调用写入接口，同样需要有效登录和操作校验码。
用户端读取公开的 GET 接口，保存后刷新即可获取新数据；当前不是多页面实时推送。

## 登录保护的实现

密码使用 Python hashlib.scrypt，加随机盐，参数 N=32768、r=8、p=3，用固定时间比较计算结果。
登录成功后生成随机会话凭据，浏览器使用 HttpOnly、SameSite=Strict Cookie 保存；数据库只存凭据的 SHA-256 摘要。
会话有效期为 8 小时，刷新页面可通过 /auth/me 恢复登录；退出时删除服务端会话，旧 Cookie 无法继续使用。
账号停用或会话过期同样返回 401。

写入请求要求 X-CSRF-Token，登录要求 X-Admin-Request；还会检查请求 Origin。未开放携带凭据的跨域访问。
本机 HTTP 下 Cookie 的 Secure 为 false，上线 HTTPS 时必须配置 COOKIE_SECURE=true，并将 ADMIN_ALLOWED_ORIGINS 设置为实际网站域名。
5 分钟内同一客户端连续 10 次登录失败后返回 429。该限速保存在单个进程内，未来多实例部署需改为共享存储；当前本机单进程适用。

## 数据规则

- 地点与道路编号不允许修改；新建时必须唯一。
- 地点代码以大写字母开头，只包含大写字母、数字和下划线，代码唯一；名称不能只有空格。
- 纬度和经度必须成对填写或成对留空，检查范围，未知坐标仍留空。
- 道路端点必须存在，不能连接同一个地点，距离必须是正整数。
- 当前表约定 start_id < end_id，双向记录允许往返；单向记录只允许小编号到大编号。反方向单向道路暂不支持，后续如需要应迁移此存储约定。
- 不允许重复的道路端点组合。涉及唯一性冲突返回 409，提交失败会回滚。
- 删地点前检查关联道路，数据库外键也会阻止产生悬空道路。

前端对新代码的地点自动分配人工示意位置；原始示例名称有中文别名，管理员更名后优先显示新名称。当前示意图线条没有单向箭头，通行方向在后台道路列表查看，实际算法遵守方向。
