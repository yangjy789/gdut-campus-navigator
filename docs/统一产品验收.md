# 统一产品验收（2026-11-24）

产品：GDUT Campus · 校园探索与智能导览，版本 1.0.0。

## 本次整合

取消访客侧的数据版本切换，统一为校园探索、步行查询和智能助手。访客页面、管理页面及对外知识说明中移除旧的开发过程用语；保留地点来源、规划状态、图上位置精度和第三方服务说明。

数据库迁移 0004 新增 campus_places，首次导入 51 条地点；管理员与访客读取同一表。地点创建、更新、删除与 CSRF、认证、资料链接和图上坐标校验已测试。已有路网算法组件和历史测试保持隔离，不在访客地图中冒充实际校园路网。

问答端点 /api/campus/real/ask 将 Chroma 检索的通用资料与数据库实时目录进行排序；排除历史地点快照，避免后台改名或删除后继续引用旧条目。自然语言问路使用明确句式或模型工具调用，地点解析只接受完整、唯一名称或别名。

路线接口只生成带校园和城市范围的百度地图步行链接，distance_m=null。HTTP 入口返回 200，浏览器已打开名称与起终点相符的百度地图页面；该外部页面的完整路线面板因浏览器读取超时未完成自动核验，不宣称已验证全部地点在外部地图中的匹配与可步行性。
